# Estalia Studio — site v8

Refonte de la v7 pour qu'elle ne ressemble pas à un site fait par IA. Le parti pris vient du métier : un plateau de tournage et une table de montage.

- Typographies : Big Shoulders Display pour les titres (condensée, en capitales), Schibsted Grotesk pour le texte, IBM Plex Mono pour les étiquettes techniques (timecode, formats).
- Couleurs : papier, encre et un seul rouge, celui du voyant REC.
- Éléments : horloge REC en direct, viseur caméra sur la vidéo du hero (coins, timecode), bandeau des secteurs, grille de films lus au survol, calendrier des packs sur 12 mois, onglets Commerces / Immobilier.
- Contenus, tarifs et vidéos : identiques à la v7.

```
npm ci
npm run dev
npm run build
```
