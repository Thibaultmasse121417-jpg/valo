# Estalia Studio — site v9

Version sobre et professionnelle, faite après la v8 jugée « trop IA ».

- Une seule famille de caractères (Schibsted Grotesk), titres en minuscules, IBM Plex Mono réservé aux petites infos (durées, formats).
- Fond clair, encre, rouge réservé aux boutons d'action.
- Pas de gadgets : pas d'horloge, pas de bandeau défilant, pas de numérotation décorative.
- Parcours : secteurs → réalisations et découpage → méthode → tarifs → saisons (échéance calculée) → comparatif → questions → contact.
- Formulaire simple. Un choix de secteur ou d'offre préremplit l'activité et l'offre.

```
npm ci
npm run dev
npm run build
```
