# Domain research

**No domain was purchased.** Per the brief, this is research only — the
owner authorises and buys.

## Important finding: a real naming risk

Two things turned up in live search that should be resolved **before**
committing to "Estalia" as the final brand name, not after:

1. **`estalia.com` is already registered and live** — the page returns
   an active privacy notice (not a parked/for-sale placeholder), meaning
   it's a real, in-use site. It is not available at any price without a
   direct approach to the current owner.
2. **`estaliacordoba.com` is a real, existing hospitality business**
   trading under the name "Estalia" (a hotel-related property in
   Córdoba, Spain — confirmed via search, the site itself couldn't be
   fetched directly to see full details). This is a genuine
   naming-collision risk *specifically in the hospitality industry* —
   the exact market Estalia Studio is launching into. It doesn't
   necessarily block using "Estalia" (different country, different
   business type — a content studio vs. a hotel), but it means a proper
   trademark clearance check (UK IPO + EUIPO, since the studio is
   UK-market and Córdoba is in the EU) is worth doing before any
   material brand investment (paid ads, signage, a trademark filing of
   Estalia's own) — this a step for the owner or a solicitor, not
   something this session can verify or clear.

Neither finding is necessarily fatal — "Estalia" as a content-studio
brand name and "Estalia" as a Spanish hotel are different goods/services
classes — but it's exactly the kind of thing worth 20 minutes of a
trademark search before, not after, ordering signage or filing a mark.

## Domain candidates to check manually

Live registrar availability could not be checked for most of these from
this session (registrar/WHOIS lookup sites were blocked by network
policy here) — the owner should verify current availability directly at
a registrar (e.g. Namecheap, GoDaddy, Cloudflare Registrar) before
deciding.

| Candidate | Notes |
|---|---|
| `estalia.com` | **Confirmed taken**, in active use — not available |
| `estaliastudio.com` | Matches the site's current working name exactly; check availability |
| `estalia.studio` | Matches the "STUDIO" wordmark treatment already used in the logo; on-brand, but a less common TLD for a UK B2B buyer who may default to typing `.com` |
| `getestalia.com` | Common, clean pattern for a service brand if `.com` bare is unavailable |
| `tryestalia.com` | Same pattern, slightly more "software" in tone — probably not the right register for a premium hospitality studio |
| `estalia.co` | Short, clean, but `.co` can read as a typo of `.com` in print/email |
| `hello-estalia.com` | Fallback only — reads slightly awkward as a primary domain |

## Recommendation

1. Resolve the naming-collision question first (a short trademark check
   in the UK/EU, hospitality + creative-services classes).
2. If "Estalia" clears, `estaliastudio.com` is the strongest available
   candidate seen so far — it's already the working name across the
   codebase (`siteConfig`, email convention, page titles), so it needs no
   further rebrand if secured.
3. Buy for a minimum of 2 years and enable auto-renew + WHOIS privacy at
   purchase — both routine, cheap, and prevent an embarrassing lapse
   later.
4. Do not buy anything until the owner has made this decision — this
   document is input to that decision, not an instruction to execute it.
