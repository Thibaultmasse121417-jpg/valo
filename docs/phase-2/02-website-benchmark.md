# Website benchmark

Ten reference categories relevant to Estalia's positioning, analysed for
**patterns**, not identity — nothing below was copied; each row states
what the site actually does, then whether Estalia should keep, adapt, or
ignore it.

| # | Reference (category) | What it does |
|---|---|---|
| 1 | Buck (buck.co) — creative content studio | Full-bleed video hero, minimal 4-item nav, work grid as the entire homepage body |
| 2 | Instrument (instrument.com) — creative agency | Large serif/grotesque headline pairing, case studies as the primary nav item |
| 3 | Ueno (ueno.co) — digital product studio | Confident single-sentence value prop, logo wall kept small and low-key |
| 4 | Aman (aman.com) — luxury hospitality brand | Near-full-viewport imagery, near-silent copy, price hidden behind an enquiry flow |
| 5 | COMO Hotels (comohotels.com) — hotel group | Editorial photography grid, restrained colour, property-first navigation |
| 6 | Soho House (sohohouse.com) — hospitality membership brand | Editorial magazine tone, member proof used instead of specs, warm neutral palette |
| 7 | Ace Hotel (acehotel.com) — boutique hotel group | Personality-driven copy, city-by-city structure, unpretentious CTA language |
| 8 | One Thousand Birds — video production studio | Reel-first homepage, minimal chrome, credits list as trust signal |
| 9 | Linear (linear.app) — modern SaaS | Extremely restrained motion, one accent colour, pricing shown as a clear comparison, not a sales pitch |
| 10 | Framer (framer.com) — modern SaaS/creative tool | Editorial pricing cards (not generic SaaS tiles), "most popular" badge treatment, strong before/after demo pattern |

## Pattern-by-pattern verdict

| Pattern | Verdict | Reasoning / what Estalia does |
|---|---|---|
| Hero structure (near-full-viewport, one clear headline) | **KEEP** | Matches #1, #4, #8. Estalia's hero is a single confident headline over a near-full-viewport frame — currently a placeholder frame until real footage exists, never a stock stand-in. |
| Typography (editorial serif + modern grotesque pairing) | **KEEP** | Matches #2, #6. Bodoni Moda + Archivo — see brand system doc. |
| Dense multi-item navigation | **IGNORE** | Agency sites (#2, #3) often carry 6–8 nav items once they have many services/case studies. Estalia isn't there yet — brief caps nav at 5 items + CTA, which is closer to #9/#10. |
| Portfolio as before/after pairs | **ADAPT** | #10's demo pattern (a clear before/after) is the single most relevant borrowed structure — adapted into the "Immediate Proof" section right after the hero, framed explicitly as source photo → Estalia result. |
| Video-first homepage body | **ADAPT** | #1 and #8 make the whole homepage a work reel. Estalia adapts this at a smaller scale (4 portfolio demos, not a continuous reel) because trust and process need to be established first for a B2B hospitality buyer who doesn't already know the studio. |
| Price hidden behind enquiry | **IGNORE** | #4's approach (no visible price) suits ultra-luxury hospitality selling stays, not a productised monthly service. Estalia's ICP (an independent hotel GM) explicitly wants "How much?" answered in under 30 seconds — brief requirement — so pricing is shown directly, editorially, like #10. |
| Editorial pricing cards, not generic SaaS tiles | **KEEP** | Matches #10 directly — bordered panels, serif numerals, a "most popular" badge without a plastic/rounded SaaS look. |
| Restrained, single-pass motion | **KEEP** | Matches #9. One reveal per element, once, no loop, no bounce. |
| Case studies as primary nav item | **IGNORE** | Appropriate for #2/#3 who have dozens of real, named clients. Estalia has none yet — the equivalent nav item is "Work," pointing to labelled concept demonstrations, never framed as client case studies. |
| Membership/community proof (logos, quotes) | **IGNORE (for now)** | #6's member social proof requires real members. Estalia has zero real clients at launch — brief's absolute prohibition on fake testimonials/logos applies. Testimonial/logo components are scaffolded but hidden, ready for real data later. |
| Personality-forward, informal copy | **IGNORE** | #7's playful tone suits a lifestyle hotel brand talking to travellers. Estalia is B2B, talking to a hotel GM/owner — tone stays premium, short, confident, understated (brief §36), not playful. |
| Mobile: video autoplay behaviour, poster-first loading | **KEEP** | Universal across #1, #8, #10 — muted/looped/poster-first video, never autoplay-with-sound, never a layout that only works on desktop. |

## What this ruled out

No single brand's navigation structure, colour system, logo type, or copy
voice was reused. The only concrete borrowed structure is the
before/after demo pattern (#10) and the editorial pricing card treatment
(#10) — both used because they map directly onto Estalia's actual product
(before/after transformation of existing assets, three clear paid tiers),
not because they look distinctive.
