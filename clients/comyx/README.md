# Maquette Comyx Prestige — boutique « portant »

Proposition pour Comyx Prestige (concept store à Amiens, comyx.fr) :
- `index.html` : la nouvelle collection de novembre sur le portant. Ce sont les vraies pièces, avec leurs vrais prix, tailles et couleurs (repris de comyx.fr). On y trouve la fiche avec choix de couleur, la grille filtrable et le panier (paiement désactivé dans la maquette).
- `atelier/` : l'espace où la boutique ajoute ses pièces (démonstration, gardée dans le navigateur).
- Identité : logo, couleurs (crème, brun, camel), messages de la boutique (Amiens, du mardi au samedi de 10 h à 19 h, THANKYOU10, Alma en 3 fois dès 100 €, retours sous 14 jours).

Les photos sur cintre de `public/media/pieces/` ont été **recréées par IA** à partir des photos portées de comyx.fr, puis détourées. Il faut les faire valider par la boutique avant toute mise en ligne.

Ce n'est pas un site officiel de Comyx Prestige : c'est une maquette commerciale à montrer à la boutique.

```
npm ci
npm run dev
npm run build
```
