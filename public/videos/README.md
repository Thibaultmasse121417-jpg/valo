# Vidéos — où déposer chaque fichier

Les vidéos sont organisées par univers. Déposez vos fichiers avec
exactement ces noms pour qu'ils remplacent automatiquement les
placeholders élégants affichés sur le site — tant qu'un fichier est
absent, le site affiche un plan fixe (poster) ou un placeholder
éditorial, jamais un lecteur cassé ni de zone vide.

| Fichier | Utilisation |
| --- | --- |
| `hero.mp4` | Vidéo plein écran de la page d'accueil (`/`) |
| `real-estate/hero.mp4` | Hero de la landing page `/real-estate` |
| `real-estate/chateau.mp4` | Projet — Château, Normandie |
| `real-estate/villa.mp4` | Projet — Villa, Côte d'Azur |
| `real-estate/paris.mp4` | Projet — Appartement, Paris |
| `wedding/hero.mp4` | Hero de la landing page `/wedding-venues` |
| `wedding/domaine.mp4` | Projet — Domaine, Provence |
| `hospitality/hero.mp4` | Hero de la landing page `/hospitality` |
| `hospitality/boutique-hotel.mp4` | Projet — Boutique Hotel, Paris |
| `hospitality/restaurant.mp4` | Projet — Restaurant, Paris |
| `business/hero.mp4` | Hero de la landing page `/business` |
| `business/showroom.mp4` | Projet — Showroom automobile, Paris |

Recommandations :
- Format **MP4 (H.264)**, la lecture se fait en `muted` côté site.
- Compression web (≈ 1080p, débit modéré) pour préserver la vitesse de chargement.
- Voir aussi `public/images/` pour les images "poster" associées (affichées
  tant que la vidéo correspondante n'est pas en ligne, ou en attendant
  son chargement).
