# Vidéos — à déposer ici

Déposez vos fichiers vidéo réels avec exactement ces noms pour qu'ils
remplacent automatiquement les placeholders élégants affichés sur le site :

| Fichier              | Utilisation                          |
| --------------------- | ------------------------------------- |
| `hero.mp4`             | Vidéo plein écran de la section Hero |
| `chateau.mp4`          | Projet — Château, France             |
| `villa.mp4`            | Projet — Villa, Côte d'Azur           |
| `paris.mp4`            | Projet — Appartement, Paris           |
| `domaine.mp4`          | Projet — Domaine, Provence            |

Recommandations :
- Format **MP4 (H.264)**, silencieux ou avec piste audio coupée côté lecteur (le site les lit en `muted`).
- Compression web (≈ 1080p, débit modéré) pour préserver la vitesse de chargement.
- Tant qu'un fichier est absent, le site affiche automatiquement un
  placeholder éditorial élégant (jamais de lecteur cassé ni de zone vide).

Voir aussi `public/images/` pour les images "poster" associées.
