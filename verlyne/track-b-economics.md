Puis, par offre (A 44,95€ / B 54,95€ / C 69,95€) :

```
CONTRIBUTION MARGIN = PRIX OFFRE − VERIFIED LANDED COST − FRAIS DE PAIEMENT − TVA
VERIFIED CPA BE     = CONTRIBUTION MARGIN (marge dispo pour absorber le CPA, seuil de rentabilité)
TARGET CPA          = VERIFIED CPA BE × (1 − marge nette cible souhaitée, ex. 25-30%)
TARGET ROAS         = PRIX OFFRE / TARGET CPA
```

### 4 niveaux à produire dès devis reçu

| Niveau | Définition |
|---|---|
| EXCELLENT CPA | CPA permettant une marge nette confortable (objectif, pas juste rentable) |
| TARGET CPA | CPA visé en régime de croisière |
| ACCEPTABLE CPA | CPA encore rentable mais marge réduite |
| BREAK-EVEN CPA | Seuil de rentabilité — ligne rouge, jamais l'objectif |

Rappel : l'objectif n'est **pas** le break-even. Ces 4 niveaux seront calculés pour les 3 offres (SOLO/GIFT/PREMIUM) dès que le Landed Cost sera vérifié.
